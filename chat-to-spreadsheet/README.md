# Google AI Studio to Spreadsheet Importer (GAS)

## 概要

Google AI Studio の会話スレッドのファイルから、質問文と回答文のテキストを抽出し、Google スプレッドシートへ読み込む Google Apps Script (GAS) です。

Google Drive の `Google AI Studio` フォルダに保存されているスレッドファイル（JSON形式）を読み込みます。

## 会話スレッドから抽出する要素

- ユーザーの質問文
	- タイムスタンプも抽出します。
- AIの回答文
	- AIの思考ログは除外します。
	- 注釈リンクURLは、リダイレクトページを挟んだまま出力します。

---

## 前提条件

- 取り込みたい会話スレッドが履歴に保存されている必要があります。2026年9月現在の時点では、Temporary chat（一時チャット）を使用しない限り、スレッドは基本的に自動保存されるようです。
- 対象となる会話スレッドには、他のスレッドと重複しないタイトルをつけておきます。

## セッティング

1. **Google スプレッドシート** を新規作成します。
2. メニューバーの **「 拡張機能 」 ＞ 「 Apps Script 」** をクリックします。
3. スクリプトエディタが開いたら、デフォルトで記述されている内容をすべて削除します。
4. `chat-to-spreadsheet.gs` の内容をすべてコピーして貼り付けます。
5. **「 保存 」** ボタンまたは `Ctrl + S` で保存します。
6. スプレッドシートのタブに戻り、ブラウザでページをリロードすると、メニューバーの右側に **`AIチャットを読み込み`** というカスタムメニューが追加されます。

## 使い方

1. メニューバーの **「 AIチャットを読み込み 」 ＞ 「 スレッド名を指定して読み込む 」** を選択します。
2. ダイアログが表示されたら、インポートしたいスレッド名を入力して **「 OK 」** を押します。
3. スレッド名と同名のページが新規作成され、チャットの内容がインポートされます。

> [!NOTE]
> 同名のスレッドを再読み込みした場合は、連番をつけたページが新規作成されます（例: `スレッド名 (1)`）。

> **初回実行時の権限承認について:**
> 初めてスクリプトを実行する際、Google DriveとGoogleスプレッドシートへのアクセス権限を認証するためのポップアップが表示されます。
> `詳細` ＞ `(安全ではないページ) に移動` を選択し、アクセス権限のチェックボックスを有効にして認可してください。
